# IronSpark Studios — Website Content Needs
**Prepared for leadership review**
**Last updated: May 2026**

The site's visual foundation is complete. What's missing is the content that turns a good-looking website into a credible business. This document outlines exactly what we need, who needs to provide it, and why each item matters.

---

## 🔴 Critical — Blocks investor / client credibility

### 1. Founder Bios
**Where it lives:** About page — "The Team" section

The site currently has placeholder cards. We need:

| Field | Founder 1 | Founder 2 |
|---|---|---|
| Full name | | |
| Title / role | | |
| Headshot (photo) | High-res, professional or editorial | Same |
| Bio (2–3 sentences) | Previous work, specific credits, what you bring | Same |
| LinkedIn URL (optional) | | |

> **Why it matters:** Investors and clients back people, not logos. No names = no trust.

---

### 2. Real Portfolio Work
**Where it lives:** Work page is currently hidden and redirects to Services until this is ready.

We need **at least 2–3 real case studies** — one entertainment, one healthcare, ideally one of each that shows a full arc (brief → process → result).

For each project, provide:

- **Project name** (or client name, if public)
- **What we made** — e.g., "6-episode animated pilot," "3-video patient education series"
- **Who it was for** — client/org name, or a general description if NDA applies (e.g., "a regional health system in the Southeast")
- **The problem we solved** — 1–2 sentences
- **Outcome or deliverable** — what shipped, any measurable result if available (e.g., "deployed across 12 hospital waiting rooms," "pilot selected for network review")
- **Visuals** — stills, frames, or a brief clip we can embed or screenshot

> **Why it matters:** For an animation studio, the portfolio IS the pitch. The Work page will return to the nav once it has real content. A placeholder is better than fake work.

---

### 3. At Least One Named Client or Partner
**Where it lives:** About page or homepage — a single "Clients / Partners" line or logo row.

Even one recognizable name (hospital system, network, brand, nonprofit) anchors everything else. If client names are under NDA, use categories: "Regional Health System," "National Children's Network," etc.

> **Why it matters:** "30+ projects" with no names reads as inflated. One real name makes the whole narrative credible.

---

## 🟡 Important — Strengthens positioning

### 4. The Business Thesis (in your own words)
**Where it lives:** About page — currently a placeholder paragraph.

In 2–4 sentences, answer: *Why does a studio that does both entertainment AND healthcare make sense?*

Questions to answer:
- What's the shared skill set or philosophy?
- Is there a specific market insight driving the dual focus? (e.g., Birmingham healthcare economy, content-as-medicine trend, kids' media meeting health literacy)
- What does the combination make possible that a single-focus studio can't do?

> You don't need to sound like a pitch deck. Just say it plainly — we'll edit it to match the site's voice.

---

### 5. Honest Stats
**Where it lives:** About page stat row, Work page intro

Replace or verify the following with real numbers:

| Stat | Current | Replace with |
|---|---|---|
| Projects completed | "30+" | Actual number, or remove |
| Years active | "4+" | Fine if accurate (founded 2020) |
| In-house production | "100%" | Keep — this is a genuine differentiator |

> If we don't have 30 completed projects yet, that's fine — just remove the number. Fewer real projects are better than inflated ones.

## 🟢 Nice to Have — Adds depth when ready

### 7. Press or Recognition
Any mention in editorial, festival selections, awards, or industry publications. Even a local Birmingham news mention is worth including.

### 8. Testimonials
One quote from a real client — even a brief one — on the Services or About page. Format: quote, name, title, org.

### 9. Social Proof
The footer links to Instagram and LinkedIn. Make sure both accounts:
- Are active (even minimally)
- Match the studio brand
- Won't be the first thing a skeptical investor checks to find no posts
